# Packages bundled into the relocatable Python tarball.
#
# This is the "default" variant: a build with no variant suffix on its tag
# (e.g. tag v3.10.20, or `./build.sh 3.10.20`) uses this file and produces
# python<VERSION>-c6-relocatable.tar.gz — today's historical filename.
#
# To add another variant, drop a sibling file here named <variant>.txt and
# tag/build with that variant (e.g. tag v3.10.20+minimal, or
# `./build.sh 3.10.20+minimal`, uses requirements/minimal.txt and produces
# python<VERSION>-<variant>-c6-relocatable.tar.gz). See README "Variants".
#
# Notes for adding more packages:
#   - Pure-Python packages "just work" anywhere.
#   - C-extension packages need a manylinux wheel compatible with glibc 2.12
#     (manylinux1 / manylinux2010 / manylinux_2_5 / manylinux_2_12). Many
#     modern projects no longer publish those, so pip will fall back to
#     building from source — which may need extra -devel packages added to
#     the yum install in the Dockerfile.
#   - After build, scripts/relocate.sh rewrites RPATHs and shebangs so the
#     install can be extracted anywhere.
certifi
requests
pycryptodome
pexpect
# lxml has no manylinux wheel compatible with glibc 2.12, and CentOS 6's system
# libxml2 (2.7.6) is a decade too old to build a modern lxml against (missing
# XML_WITH_ICU / XML_WITH_LZMA, etc.). The Dockerfile builds current libxml2 +
# libxslt from source into the prefix (like OpenSSL/SQLite) and lxml links
# against those shared libs; relocate.py then bundles and rpath-fixes them.
lxml
